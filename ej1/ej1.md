# Sistema de manejo de notas

Crear un sistema que permita manejar las notas de Programación I de una serie de alumnos.

Habrán 5 notas en total, y por defecto no estarán cargadas.

Crear un diccionario "notas" que contenga como claves los apellidos de 5 alumnos y como valores las listas vacías que van a contener las notas.

Crear un menú de opciones que contendrá las siguientes opciones:

1. Ver todas las notas
    Mostrará todas las notas de cada alumno.
2. Ver notas por alumno
    Mostrará las notas de un alumno en particular.
3. Cargar notas
    Permite seleccionar un alumno por apellido y cargar 5 notas.
4. Promedio
    Dado un alumno en particular permite ver su promedio.
